### Playwright Fundamentals — Module 1

This lab supports **Module 1: Environment & Your First Test** of *Playwright Fundamentals — Test Automation from Zero*.

Killercoda has handed you a real, empty Ubuntu virtual machine. There is no Node.js, no browsers, nothing pre-installed for testing — exactly what you'd get spinning up a fresh CI runner or a new laptop. In the next ~20 minutes you will:

1. Install Node.js from scratch.
2. Install `@playwright/test` and a real Chromium browser, including the system libraries Chromium needs to run on a bare Linux box.
3. See what Playwright's **codegen** recorder produces, and author that same test by hand (we'll explain exactly why, in Step 3).
4. Run the test against a real, live website and look at the HTML report.

Nothing here is simulated. Every command below runs against your own throwaway VM and a real public demo site.

Click **Start** when you're ready.
